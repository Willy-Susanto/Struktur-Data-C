# 🗂️ Struktur Data dengan C

Repo ini berisi catatan dan implementasi materi **Struktur Data** menggunakan bahasa C. Setiap modul dilengkapi kode yang bisa langsung dijalankan, bukan cuma pseudocode atau teori di atas kertas.

## 📚 Daftar Modul

| # | Modul | Fokus |
|:--|:------|:------|
| 01 | **ADT** | Abstract Data Type: konsep pemisahan antara interface dan implementasi |
| 02 | **Matriks** | Representasi dan operasi pada struktur data dua dimensi |
| 03 | **Stack** | LIFO, operasi push/pop, dan studi kasus penggunaannya |
| 04 | **Queue** | FIFO, enqueue/dequeue, dan variasinya |
| 05 | **Pointer** | Manajemen memori, pointer ke pointer, dan hubungannya dengan struktur data dinamis |
| 06 | **Linked List 1** | Single linked list: insert, delete, traversal |
| 07 | **Linked List 2** | Double & circular linked list |
| 08 | **Multi List** | Linked list dengan lebih dari satu relasi antar node |
| 09 | **Fungsi Rekursif** | Konsep rekursi, base case, dan implementasi pada struktur data |
| 10 | **Rekursif List** | Traversal dan operasi rekursif pada linked list |
| 11 | **Binary Tree** | Struktur pohon biner, traversal inorder/preorder/postorder |
| 12 | **Sorting** | Bubble, selection, insertion, merge, dan quick sort |
| 13 | **Searching** | Linear search, binary search, dan efisiensinya |

## 🚀 Cara Jalankan

Pastikan sudah ada **GCC** di sistem kamu, lalu:

```bash
cd 03_Stack
gcc main.c -o main
./main
```
